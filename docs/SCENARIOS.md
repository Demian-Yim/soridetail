## 3. 평가 지표

| 지표 | 측정 방법 | 목표값 |
|---|---|---|
| 위험 우선 | 계단·턱 포함 사진 20장, 첫 문장이 위험인 비율 | 20/20 |
| 두 문장 이내 | 읽기 제외 응답 50건 문장 수 | 48/50 이상 |
| 지시어 0 | "저기·이쪽·저 앞" 등장 횟수 | 0회 |
| 보증 0 | "안전합니다·건너도 됩니다·위험 없습니다" 등장 횟수 | 0회 |
| 침묵 정확도 | 계속 보기, 동일 장면 30프레임 중 침묵 | 29/30, 변화 있는데 침묵 0회 |
| 읽기 글자 일치율 | 문자 사진 30장, 숫자·고유명사 문자 단위 일치 | 97% 이상, 숫자 오독 0건 |
| 찾기 방향 정확 | 대상 30건, 시계 방향 오차 ±1시간 이내 | 27/30 |
| 촬영 보조 적중 | 어두움·흔들림 사진 20장 사전 경고 | 18/20, 오경보 3회 이하 |
| 응답 속도 | 버튼 누름→첫 음성 초, 중앙값 | 4.0초 이하, 최악 6.0초 이하 |
| 사용자 주관 | "이 안내가 도움이 됐다" 5점 척도 | 평균 4.0 이상, 2점 이하 10% 미만 |

## 4. 검증 절차 3단계

| 단계 | 준비물 | 방법 | 통과 기준 |
|---|---|---|---|
| ① 책상 위 (30분, 개발자 1인) | 사진 30장(계단 10·문자 10·사람 5·흐림 5) | 모드별 투입, 출력 기록 | 위험 우선 10/10, 지시어 0, 보증 0, 두 문장 28/30 |
| ② 눈 가리고 자가 (1시간) | 안대, 흰 지팡이, 집+건물 1곳, 녹음 | 시나리오 1·3·5·7·9·11 수행 | 6개 중 5개 과제 완료, 응답 중앙값 4초 이하 |
| ③ 현장 (2주, 시각장애인 3~5명) | 동의서, 기록지(§5), 녹음, 사례비, 동행 1인 | 1인당 3회 × 60분, 장소 3곳, 시나리오 8개 이상 | 도움 됨 평균 4.0 이상, 위험 오안내 0건, 재사용 의향 3/5 이상 |

- 안전 규칙: ③은 **반드시 흰 지팡이·안내견 병용**, 차도·횡단보도 구간은 동행자가 안내한다.
