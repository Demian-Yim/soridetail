## 1. 제품 한 줄 · 두 얼굴 원칙

**헤이 비전은 눈앞을 말해주는 AI 안내다. 전부 설명하지 않고 지금 필요한 한 문장만 말한다.**

이 제품은 **보는 사람과 사는 사람이 다르다.** 그래서 화면을 두 얼굴로 나눈다.

| | ① 문서 얼굴 `.hv-doc` | ② 접근성 얼굴 `.hv-a11y` |
|---|---|---|
| 누가 보나 | 가족 · 복지관 · 특수학교 · 지자체 · 기업 접근성 담당 | 시각장애인 · 저시력 당사자 |
| 어디에 | 랜딩 화면 보기 뷰, 앱 보기 모드 | 랜딩 입장 게이트·소리 안내 뷰, 앱 소리 모드 |
| 목적 | 도입 판단(신뢰·근거·절차) | 지금 바로 쓰기(오조작 없이) |
| 색 | 화이트 기조 + 네이비/블루 강조 (DGRS) | 검정 + 흰 글자 + 노랑 (최대 대비) |
| 읽는 거리 | 30~60cm, 정독 | 화면을 거의 안 본다 / 코앞 확대 |

**철칙:** ②의 검정·노랑은 브랜드 장식이 아니라 **저시력 접근성 요구**다. DGRS 색으로 바꾸지 않는다.
바꾸는 것은 색이 아니라 **간격·타이포 위계·컴포넌트 완성도**이며, 그것은 두 얼굴이 `hv.css` 한 파일을 공유한다.

## 2. 레퍼런스 매칭 (refero 5선 중 1개)

**선택: Linear** — 제품형 랜딩. 넉넉한 세로 리듬(섹션당 96px), 좌측 정렬 큰 제목, 얇은 구분선 한 줄로 섹션을 나누고, 장식 대신 **제품 화면 자체**를 히어로에 놓는 방식.

- 가져온 것: 섹션 구분선(1px `--hv-line`) · eyebrow 라벨 + 큰 제목 + 보조문 3단 헤더 · 카드 그림자 최소화 · 히어로 우측 제품 목업.
- 버린 것: Linear 특유의 **다크 히어로 · 보라 글로우 · 그라디언트 블롭**(Anti-Slop 금지 항목). 배경은 흰색 고정.
- 대신 넣은 것: **손그림 화이트보드 다이어그램 4종**(`.hv-board`). DGRS 이중부호화를 Linear 골격 위에 얹는다.

### 3-2. 타이포 (시스템 스택 · 웹폰트 URL 0)

`Pretendard → Apple SD Gothic Neo → Malgun Gothic → -apple-system → Segoe UI`

| 단계 | 문서 얼굴 | 접근성 얼굴 |
|---|---|---|
| 제목 1 | `clamp(31px, 5.2vw, 52px)` / 800 | 27px / 800 (안내 문장) |
| 제목 2 | `clamp(24px, 3.4vw, 36px)` / 800 | 24px / 800 |
| 본문 | 16px / 400~500 | 19~21px / 400 |
| 캡션 | 13~14px | 15~16px |
| 주 버튼 | 16px / 800 | 21~33px / 800 |

`word-break: keep-all`로 한국어 단어가 잘리지 않게 하고, 행간은 본문 1.6 · 제목 1.18~1.25.

### 3-3. 간격 · 반경 · 그림자

8pt 배수(`--hv-s1`~`--hv-s9`, 4~96px). 섹션 세로 96px(모바일 56px), 카드 안쪽 24px, 그리드 간격 16px.
반경 10/14/20/28/999px. 그림자는 2단뿐이며 둘 다 거의 보이지 않는 수준(`rgba(17,17,17,.04~.07)`).

## 5. 레이아웃 · 반응형

- 최대 폭 1120px(랜딩) / 1200px(앱), 좌우 여백 20px.
- 그리드 전환점: 600px(2열) · 760px(3열) · 960px(히어로 7:5, 앱 62:38) · 1000px(4열).
- 앱 보기 모드는 **좌측 카메라 스테이지 + 우측 기록/설정** 2단. 960px 미만에서 세로 1단.
- 320px·375px·390px에서 가로 스크롤 0을 실측으로 확인한다(`scrollWidth === clientWidth`).

## 6. 다이어그램 4종 (이중부호화 · 전부 라벨 붙은 인라인 SVG)

모두 `.hv-board` 위에 얹고, `role="img"` + `aria-label`로 **그림 내용을 문장으로 다시 말한다.**
손글씨 감성은 폰트가 아니라 **SVG 획**(둥근 끝, 굵기 2.5~12, 점선)으로 낸다.

| 기호 | 그림 | 라벨 |
|---|---|---|
| ⓐ 설명 vs 안내 | 왼쪽 9줄 회색 막대 / 오른쪽 굵은 네이비 1줄 | "보통의 AI — 9문장 / 읽는 데 24초" ↔ "헤이 비전 — 1문장 / 듣는 데 3초" |
| ⓑ 시계 방향 | 원 + 12·3·6·9시 눈금, 중앙 사람, 2시 방향 점선 + 발자국 3개 | "12시 — 정면", "2시 방향 세 걸음" |
| ⓒ 우선순위 3단 | 폭이 줄어드는 3단 막대(빨강→네이비→블루) + 좌측 화살표 | "1 위험한 것 / 2 길·방향 / 3 요청한 것", "먼저 → 나중" |
| ⓓ 사생활 흐름 | 폰 → 점선 격리 박스(점검·판독) → 문장만 회신, 하단 빨간 점선 삭제 경로 | "사진 1장", "일회용 격리 컴퓨터", "문장만 돌아옴", "세션이 끝나면 모두 삭제" |

**도형에는 반드시 라벨을 붙인다.** 라벨 없는 원·노드 나열은 금지(모호한 추상 도형).

## 7. 접근성 계약 (WCAG 2.2 AA)

1. 텍스트 대비 **4.5:1 이상** — §3-1 전 토큰 실측 표기. 비텍스트(테두리·아이콘) 3:1 이상.
2. **색에만 의존하지 않는다** — 상태는 색 + 테두리 + 점 모양 + 글자 라벨 4중.
3. 터치 대상 **48px 이상**, 접근성 얼굴은 **72px 이상**(주 버튼은 화면 높이의 38%).
4. 포커스 링 `4px #00E5FF` + `offset 3px`, 두 배경 모두에서 보인다.
5. `aria-live`는 **모드당 하나만 활성** — 보기 모드에서는 `#visualCallout`만 assertive, 소리 모드에서는 `#voiceCallout`만 assertive. 나머지는 `off`로 내려 중복 낭독을 막는다.
6. `prefers-reduced-motion: reduce`에서 전환·애니메이션 전부 차단.
7. `lang="ko"`, 건너뛰기 링크, 모든 장식 SVG `aria-hidden`, 의미 SVG는 `role="img" + aria-label`.
8. 가로 스크롤 0(320~390px).

## 8. 콘텐츠 원칙 (판매 가능한 수준의 선)

- **없는 것을 쓰지 않는다.** 사용자 후기 · 고객 로고 · 도입 기관 수 · 수상 · 언론 보도 · 인증 마크 **0건**.
- **실측 사실만 쓴다.** 응답 약 4초 · 같은 장면이면 침묵 · 세션마다 일회용 격리 컴퓨터 · 설치 불필요.
- **금액을 지어내지 않는다.** 개인은 "시범 운영 기간 무료", 기관은 "도입 문의"까지만.
- **한계를 먼저 말한다.** 4초 지연 · 흰 지팡이/안내견 대체 아님 · 신호와 차량 판단 안 함 · AI는 틀릴 수 있음.
- 회사 표기는 **`FLOW : AX디자인연구소`** 한 가지로 고정.
- 화면에 외부 인물·기관 실명, 내부 파일 경로·스크립트명·명령어를 쓰지 않는다. `Daytona`·`Google Gemini`는 **사생활 고지에 필요한 기술 사실**이라 예외로 표기한다.

## 9. 구현 제약 (코딩 에이전트에게 넘기는 조건)

1. **네트워크 외부 리소스 0** — CDN·웹폰트 URL·외부 이미지 금지. 아이콘은 문서 내 `<symbol>` 스프라이트.
2. **JS 계약 불변** — 랜딩의 `#gate`/`#voice`/`#visual`, `?view=`, `localStorage["heyvision-ui"]`, 전역 `selectUI`·`resetToGate`·`speakSection`·`speakAll`; 앱의 전 id·키보드 단축키·`sendBeacon`·wakeLock·서비스워커.
3. **`<script src="/static/voice.js">`는 절대경로 고정.** 상대경로로 바꾸면 404로 음성이 전부 죽는다(실제 사고 이력).
4. `[hidden]{display:none !important}`를 유지한다 — `display:flex` 규칙이 `hidden` 속성을 이기지 못하게.
5. 목소리 고르개는 **컨테이너만** 둔다(`#voicePicker`, 앱 보기 모드는 `#voicePickerVisual`). 내부 DOM은 `voice.js`의 `mountPicker`가 그리며, 없으면 조용히 건너뛴다.
6. Anti-Slop: 보라 글로우 · 그라디언트 블롭 · 이유 없는 다크 히어로 · 얇은 박스 나열 + 작은 균일 텍스트 · 빈 프레임 금지.
