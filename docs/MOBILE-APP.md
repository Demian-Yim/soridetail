## 1. 지금 상태 — 설치형 웹앱 (PWA)

| 항목 | 상태 |
|---|---|
| 홈 화면에 추가 → 주소창 없는 전체 화면 앱으로 실행 | [검증] manifest·서비스워커·아이콘(192/512/마스커블/애플) 제공, 6개 주소 200 |
| 후면 카메라(눈앞) · 전면 카메라(내 모습) | [검증] 가짜 카메라 자동 시험 통과 / [미검증] 실제 폰에서 전환 |
| 자연 음성 · 목소리 6종 · 말 빠르기 4단 | [검증] |
| 진동 · 화면 꺼짐 방지 · 앱 바로가기(소리 모드/보기 모드/소리상세) | 구현됨 / [미검증] 실기기. 아이폰 사파리는 진동 미지원 |
| 앱스토어·플레이스토어 등록 | **없음** |

설치 방법 — 아이폰: 사파리에서 열기 → 공유 → 홈 화면에 추가. 안드로이드: 크롬에서 열기 → 메뉴 → 앱 설치(또는 홈 화면에 추가).

## 2. 웹앱으로는 안 되는 것 (네이티브 앱이 필요한 이유)

| 하고 싶은 것 | 웹앱 | 네이티브 |
|---|---|---|
| 전면·후면 카메라 **동시** 사용 | 불가 (브라우저는 한 번에 하나) | 가능 (기기 지원 시) |
| 화면을 끄거나 다른 앱을 쓰는 동안 계속 안내 | 불가 | 가능 |
| 볼륨 버튼·이어폰 버튼으로 "지금 알려줘" | 불가 | 가능 |
| 스마트 안경·외장 카메라 연동 | 불가 | 가능 |
| 아이폰 진동 | 불가 | 가능 |
| 스토어 검색·신뢰·기관 배포(MDM) | 불가 | 가능 |

## 3. 출시 3단계

### 1단계 — 상시 서버 (모든 것의 전제) — ✅ 2026-09-20 배포
**고정 주소: https://heyvision-990911402358.asia-northeast3.run.app** (Google Cloud Run · 서울 리전 · 프로젝트 FLOW-AI · 인스턴스 최대 1대 · 키는 Secret Manager).
발표용 임시 터널은 더 이상 쓰지 않는다. 비용 울타리: 접속 주소별·서비스 전체 하루 호출 상한(`app/limits.py`) + 10분 유휴 세션 자동 삭제.

준비된 것: `Dockerfile`(음성 모델을 이미지에 포함해 첫 실행 지연 없음) · `.dockerignore`(.env 제외) · 시크릿은 실행 시 환경변수로 주입.

```bash
# Cloud Run 예시 (서울 리전). 키는 Secret Manager 나 --set-env-vars 로 주입 — 저장소에 넣지 않는다.
gcloud run deploy heyvision --source . --region asia-northeast3 --allow-unauthenticated \
  --memory 2Gi --cpu 2 --timeout 120 --set-env-vars DAYTONA_API_KEY=...,GEMINI_API_KEY=...,CONTACT_EMAIL=...
```

- [검증] Cloud Build 로 이미지 빌드·배포 완료(2026-09-20). 재배포는 위 명령 그대로.
- [추정] 비용: 시범 규모는 Cloud Run 무료 구간 안에서 시작 가능. 다만 음성 합성이 CPU 를 쓰므로 사용자가 늘면 과금된다. **배포는 돈이 나갈 수 있는 결정이라 정훈님 승인 후 실행한다.**
- 실사용자에게 열기 전에 Gemini 를 유료 등급으로 전환할 것 — 무료 등급은 전송한 사진이 모델 개선에 쓰일 수 있다 [추정 — 약관 확인 필요].
- 사용자별 하루 호출 상한과 간단한 로그인(또는 기관 코드)을 붙여 키 남용을 막는다.

### 2단계 — 안드로이드 앱 (플레이스토어)
웹앱을 그대로 감싸는 방식(TWA). 고정 주소만 있으면 하루 안에 가능하다.

1. https://www.pwabuilder.com 에 고정 주소 입력 → Android 패키지(AAB) 생성
2. 생성된 서명 지문을 서버 `.env` 의 `ANDROID_ASSETLINKS` 에 넣는다 → `/.well-known/assetlinks.json` 이 자동으로 응답(라우트 구현됨) → 주소창 없이 열린다
3. 플레이 콘솔 등록(개발자 등록비 25달러 1회) → 내부 테스트 → 공개

이 PC 에는 Android SDK 가 없어 직접 빌드는 못 한다(자바 21 만 있음). PWABuilder 는 클라우드에서 빌드해 준다.

### 3단계 — 네이티브 앱 (2번 표의 기능이 필요해질 때)
- 아이폰 앱은 맥과 애플 개발자 계정(연 99달러)이 필요하다. 애플은 웹을 감싸기만 한 앱을 반려하므로 아이폰은 처음부터 네이티브로 간다.
- 서버의 안내 규약·음성·샌드박스 API 는 그대로 재사용한다. 새로 만드는 것은 카메라·버튼·백그라운드 처리뿐이다.
- 시작 조건: 시각장애인 3~5명 현장 검증(`docs/SCENARIOS.md` 3단계)에서 "도움 됨 4.0 이상 · 재사용 의향 3/5 이상"이 나온 뒤. 그 전에 네이티브에 돈과 시간을 쓰지 않는다.

## 4. 정훈님 결정이 필요한 것

| # | 결정 | 권고 |
|---|---|---|
| 1 | 상시 서버를 띄울 것인가 (Cloud Run) | 예 — 앱 포장·기관 시연·당사자 검증 전부의 전제. 월 비용 상한을 먼저 정한다 |
| 2 | 문의 메일 주소 (`CONTACT_EMAIL`) | 정해 주시면 랜딩의 「기관 도입 문의」가 메일로 연결된다. 지금은 저장소 이슈 링크 |

| 4 | 요금 정책 | 지금은 "개인 시범 무료 · 기관 도입 문의"로만 표기. 금액은 정훈님이 정한다 |
